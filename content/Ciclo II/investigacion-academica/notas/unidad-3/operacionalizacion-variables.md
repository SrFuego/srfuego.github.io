# Operacionalización de Variables

## Definición

**Operacionalizar** es transformar una variable abstracta (concepto teórico) en **medible** (observable), definiendo **dimensiones, indicadores e ítems** para recolectar datos empíricos.

---

## Proceso de Operacionalización

```
Variable → Definición Conceptual → Dimensiones → Indicadores → Ítems
```

**Ejemplo: Variable "Gestión Tributaria"**

1. **Definición conceptual:** Conjunto de procesos para planificar, cumplir y optimizar obligaciones tributarias
2. **Dimensiones:** 
   - Planificación tributaria
   - Cumplimiento tributario
3. **Indicadores:**
   - Planificación: % de ahorro fiscal, uso de beneficios tributarios
   - Cumplimiento: Puntualidad declaraciones, ausencia de multas
4. **Ítems (cuestionario):**
   - "¿La empresa planifica pagos tributarios anualmente?" (Sí/No)
   - "¿Cuántas declaraciones tardías tuvo en 2024?" (0-5)

## Tipos de Variables

### Por Naturaleza

| Tipo | Definición | Ejemplo Contable |
|------|-----------|------------------|
| **Cualitativa nominal** | Categorías sin orden | Tipo de empresa (SA, SRL, EIRL) |
| **Cualitativa ordinal** | Categorías con orden | Nivel de riesgo (Bajo, Medio, Alto) |
| **Cuantitativa discreta** | Números enteros | N° de auditores en firma |
| **Cuantitativa continua** | Números decimales | ROE (15.3%), Ratio corriente (1.87) |

### Por Función

| Tipo | Rol | Ejemplo |
|------|-----|---------|
| **Independiente (VI)** | Causa presunta | Capacitación NIC → |
| **Dependiente (VD)** | Efecto presunto | → Calidad EEFF |
| **Interviniente** | Afecta relación | Tamaño empresa (controla efecto) |

---

## Escalas de Medición

### Likert (Actitudes)
```
1 = Totalmente en desacuerdo
2 = En desacuerdo
3 = Neutral
4 = De acuerdo
5 = Totalmente de acuerdo
```

**Ejemplo:** "La NIIF 16 mejora transparencia de arrendamientos" (1-5)

### Dicotómica
```
Sí / No
Cumple / No cumple
```

**Ejemplo:** "¿Empresa auditada externamente?" (Sí/No)

## Ejemplo Completo: Variable "Rentabilidad"

**Definición conceptual:** Capacidad de generar beneficios respecto a inversión/ventas

| Dimensión | Indicador | Fórmula | Fuente |
|-----------|-----------|---------|--------|
| **Rentabilidad económica** | ROA | (Utilidad Neta / Activo Total) × 100 | Estado de Situación Financiera |
| | Margen operativo | (Utilidad Operativa / Ventas) × 100 | Estado de Resultados |
| **Rentabilidad financiera** | ROE | (Utilidad Neta / Patrimonio) × 100 | EEFF |
| | Utilidad por acción | Utilidad Neta / N° acciones | Memoria Anual |

**Ítems (para encuesta):**
- "Indique su ROA promedio 2024: ___%"
- "¿Su ROE superó 15% en 2024?" (Sí/No)
